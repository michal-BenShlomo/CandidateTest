# Requirements Document - חיפוש וסינון בקשות

## מבוא

הוספת יכולות חיפוש וסינון למערכת הצגת Requests הקיימת, כולל API וממשק משתמש.

---

## דרישות Backend

### REQ-1: חיפוש לפי Request Number (חלקי)
API יאפשר חיפוש חלקי לפי מספר בקשה (substring match).

### REQ-2: סינון לפי Status
API יאפשר סינון לפי סטטוס יחיד או מרובה.

### REQ-3: סינון לפי טווח תאריכי יצירה
API יאפשר סינון לפי תאריך התחלה ו/או תאריך סיום.

### REQ-4: סינון לפי סוג בקשה
API יאפשר סינון לפי Request Type.

### REQ-5: Sorting
API יתמוך במיון תוצאות.

### REQ-6: טיפול בקלט לא חוקי
API יחזיר שגיאה מתאימה עבור קלט לא תקין.

### REQ-7: הרשאות - משתמש רגיל
משתמש רגיל רואה רק Requests שבבעלותו (OwnerId) או מוקצים אליו (AssignedToUserId).

### REQ-8: הרשאות - Administrator
Administrator רואה את כל ה-Requests.

### REQ-9: אכיפת הרשאות בצד השרת
ההרשאות נאכפות בצד השרת (לא רק ב-Frontend).

### REQ-10: ביצועים
המערכת תתמוך במיליוני רשומות (סינון ברמת DB).

---

## דרישות Frontend

### REQ-11: טופס סינון
ממשק יכלול טופס עם פקדי סינון.

### REQ-12: מיון
ממשק יאפשר מיון תוצאות.

### REQ-13: טבלת תוצאות
ממשק יציג תוצאות בטבלה.

### REQ-14: חיווי טעינה
ממשק יציג אינדיקטור טעינה בזמן קריאה ל-API.

### REQ-15: חיווי שגיאה
ממשק יציג הודעת שגיאה כאשר API נכשל.

### REQ-16: חיווי אין תוצאות
ממשק יציג הודעה כאשר אין תוצאות.

---

## דרישות אופציונליות

### REQ-17: בדיקות (אופציונלי)
ניתן להוסיף בדיקות. הדגש על בחירת מקרי בדיקה משמעותיים.
